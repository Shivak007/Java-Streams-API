# Java Streams API

This project demonstrates various Java Streams API operations implemented step-by-step using GitFlow.

## Features Implemented

- Stream creation and iteration (forEach)
- Transform elements using map
- Collect results into a List (collect)
- Filter even numbers (filter)
- Find first element (findFirst)
- Find minimum and maximum (min, max)
- Calculate sum and average
- Match operations (allMatch, anyMatch)
- Sorting stream elements (sorted)

## Stream Concepts Covered

- Intermediate vs Terminal operations
- Stream pipelines
- Lazy evaluation
- Java Stream vs Collection comparison
